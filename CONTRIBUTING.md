# Contributing

Use Node 22+ and npm. Install dependencies with `npm ci`, then run `npm run dev`.
Before opening a pull request, run `npm run check` and check relevant keyboard and responsive behavior.

Keep changes focused and describe the result plus how it was verified. Gemini-related tests use mocked requests; never put real keys in tests, screenshots, or source files. Report security issues privately as described in [SECURITY.md](SECURITY.md).
